RecLink board: update over Wi-Fi (OTA)Scheda RecLink: aggiornamento via Wi-Fi (OTA)

Download firmwareScarica il firmware (fc_cam_bridge-esp32c3.bin)

  1. Power the board (flight controller on the bench, disarmed). It opens the Wi-Fi network RECLINK-XXXX (password reclinkfpv, or the one you set).Alimenta la scheda (flight controller sul banco, disarmato). Crea la rete Wi-Fi RECLINK-XXXX (password reclinkfpv, o quella impostata).
  2. Join it and open http://10.0.0.1.Collegati e apri http://10.0.0.1.
  3. Go to the System tab → Firmware update and choose the downloaded .bin. Leave erase settings off to keep your settings and camera pairing.Vai alla scheda Sistema → Aggiornamento firmware e scegli il file .bin scaricato. Lascia disattivato cancella impostazioni per mantenere impostazioni e abbinamenti.
  4. Wait for the upload to finish; the board reboots by itself (do not unplug it). The previous version stays in the other slot, so you can boot back to it from the same page.Attendi la fine del caricamento; la scheda si riavvia da sola (non scollegarla). La versione precedente resta nell'altro slot e si può riavviare dalla stessa pagina.

OTA works only while disarmed, and only on a board that already runs RecLink firmware.L'OTA funziona solo da disarmato e solo su una scheda che esegue già il firmware RecLink.

ESP32-C3 SuperMini: flash by USBESP32-C3 SuperMini: flash via USB

How do you want to install it?Come vuoi installarlo?

This browser has no Web Serial: use Chrome or Edge on a computer.Questo browser non ha Web Serial: usa Chrome o Edge da computer.

There is no USB image for this version on this page — pick the latest version, or flash it once and update over Wi-Fi (OTA) with the release file.Per questa versione non c'è un'immagine USB su questa pagina: scegli l'ultima versione, oppure caricala una volta e aggiorna via Wi-Fi (OTA) con il file della release.

  1. Use Chrome or Edge, plug the board in by USB (hold BOOT while plugging if it is not detected).Usa Chrome o Edge, collega la scheda via USB (tieni premuto BOOT mentre la colleghi se non viene rilevata).
  2. Press the button, pick the serial port, confirm.Premi il pulsante, scegli la porta seriale, conferma.
  3. Unplug and replug; join RECLINK-XXXX and open http://10.0.0.1.Scollega e ricollega; entra in RECLINK-XXXX e apri http://10.0.0.1.

Download firmwareScarica il firmware (fc_cam_bridge-esp32c3-supermini.bin)

Only works on a board that already runs RecLink firmware, while disarmed. Steps:Funziona solo su una scheda che esegue già il firmware RecLink, da disarmato. Passi:

  1. Power the board; join RECLINK-XXXX (password reclinkfpv, or the one you set) and open http://10.0.0.1.Alimenta la scheda; collegati a RECLINK-XXXX (password reclinkfpv, o quella impostata) e apri http://10.0.0.1.
  2. System tab → Firmware update, choose the downloaded .bin; leave erase settings off to keep settings and pairings.Scheda Sistema → Aggiornamento firmware, scegli il file .bin; lascia disattivato cancella impostazioni.
  3. Wait for the automatic reboot; the previous version stays in the other slot.Attendi il riavvio automatico; la versione precedente resta nell'altro slot.
