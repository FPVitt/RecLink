RecLink web flasher

Flash RecLink 0.2.0 (pre-release) over USB straight from the browser. Guides · Italiano: stessi pulsanti, vedi sotto.

Read first

Pre-release, bench-tested only, not flight tested. Flashing erases the whole flash (settings and camera pairings too). Use Chrome or Edge on a computer (Web Serial is not available in Firefox/Safari). Remove props / disconnect the flight battery while flashing.

ESP32-C3 SuperMini (generic board: LED GPIO8, MSP on UART1 GPIO6/7)

This browser has no Web Serial: use Chrome or Edge.

RecLink board (ESP32-C3 PCB: LED GPIO10, MSP on UART0 GPIO20/21)

This browser has no Web Serial: use Chrome or Edge.

ESP32-S3 dev board

This browser has no Web Serial: use Chrome or Edge.

Steps / Passi

  1. Plug the board in by USB. If it is not detected, hold BOOT while plugging it in. / Collega la scheda via USB; se non viene rilevata tieni premuto BOOT mentre la colleghi.
  2. Click the button for your board, choose the serial port, and confirm the erase. / Premi il pulsante della tua scheda, scegli la porta e conferma la cancellazione.
  3. When it finishes, unplug and replug the board; it opens the Wi-Fi network RECLINK-XXXX (password reclinkfpv), then go to http://10.0.0.1. / Al termine ricollega la scheda: crea la rete Wi-Fi RECLINK-XXXX (password reclinkfpv), poi apri http://10.0.0.1.

Updating later: use the portal's System tab with the OTA images from the Releases page (keeps your settings).
