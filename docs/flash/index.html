Install RecLink firmware

RecLink 0.2.0 (pre-release) · Guides · Italiano: i passi sono bilingui sotto ogni scheda.

Pre-release: bench-tested only, not flight tested. Remove props and disconnect the flight battery while flashing.

1. Which board do you have? / Che scheda hai?

RecLink board: update over Wi-Fi (OTA) / aggiornamento OTA

Download firmware (fc_cam_bridge-esp32c3.bin)

  1. Power the board (flight controller on the bench, disarmed). It opens the Wi-Fi network RECLINK-XXXX (password reclinkfpv, or the one you set). / Alimenta la scheda; crea la rete Wi-Fi RECLINK-XXXX.
  2. Join it and open http://10.0.0.1. / Collegati e apri http://10.0.0.1.
  3. Go to the System tab → Firmware update and choose the downloaded .bin. Leave erase settings off to keep your settings and camera pairing. / Scheda Sistema → Aggiornamento firmware; scegli il file .bin, lascia disattivato "cancella impostazioni".
  4. Wait for the upload to finish; the board reboots by itself (do not unplug it). The previous version stays in the other slot, so you can boot back to it from the same page. / Attendi il riavvio automatico; la versione precedente resta nell'altro slot.

The update only works while disarmed. A board that is not flashed yet needs a one-time USB flash: use the SuperMini or a USB programmer, or ask the board's maker. / L'OTA funziona solo da disarmato.

ESP32-C3 SuperMini: flash by USB

This browser has no Web Serial: use Chrome or Edge on a computer.

LED on GPIO8 (active-low), flight controller on UART1 GPIO6/7. Flashing erases the whole flash (settings and pairings).

  1. Use Chrome or Edge, plug the board in by USB (hold BOOT while plugging if it is not detected). / Usa Chrome o Edge; collega la scheda (tieni BOOT premuto se non viene rilevata).
  2. Press the button, pick the serial port, confirm. / Premi il pulsante, scegli la porta, conferma.
  3. Unplug/replug; join RECLINK-XXXX and open http://10.0.0.1. / Ricollega e apri http://10.0.0.1.

ESP32-S3 dev board: flash by USB

This browser has no Web Serial: use Chrome or Edge on a computer.

Development target. Flashing erases the whole flash. Same steps as the SuperMini. / Stessi passi della SuperMini.
